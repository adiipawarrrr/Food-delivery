🍔 Crave — Food Delivery Web App

A modern, responsive food delivery web application built using HTML, CSS, and JavaScript.
Crave provides a seamless UI for browsing food items, adding them to cart, applying discounts, and placing orders.

🚀 Features
🏠 Homepage with Hero Section
Attractive UI with stats and featured items
🍽️ Dynamic Menu
Category filtering (Indian, Italian, Japanese, etc.)
Real-time search functionality
🛒 Cart System
Add/remove items
Quantity controls (+ / -)
Live price updates
💸 Order Summary
Subtotal, delivery fee, taxes calculation
Promo code support (CRAVE10 for 10% discount)
📦 Checkout System
Order placement simulation with notification
📱 Responsive Design
Works on mobile, tablet, and desktop
🔔 Toast Notifications
User feedback for actions
🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript (Vanilla JS)
Styling: Custom CSS with modern UI design
Fonts: Google Fonts (Playfair Display, DM Sans)

⚙️ How to Run

Download or clone the repository:

git clone https://github.com/your-username/crave-food-app.git
Open the project folder
Run the app:
Simply open food.html in your browser
🎮 How It Works
Browse food items from the Menu page
Add items to cart using ➕ button
Modify quantity or remove items in Cart page

Apply promo code:

CRAVE10
Click Place Order to simulate checkout
